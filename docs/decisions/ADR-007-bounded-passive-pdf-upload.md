# ADR-007: Ограниченная проверка исходного PDF без изменения оригинала

Status: accepted. Date: 2026-10-15.

## Context

В supporting documents требовался исходный PDF. Принимать файл по расширению или MIME недостаточно: PDF может включать формы, JavaScript, вложения, действия и ресурсоёмкую структуру. Проверяемая копия должна сохранять исходные байты и SHA; автоматическая очистка изменила бы документ и могла бы повредить подпись.

## Options Considered

- Принять PDF по сигнатуре: просто, но не проверяет структуру и активное содержимое.
- Пересобрать/отрендерить каждый PDF: меняет оригинал, требует отдельного доверия к renderer и политике подписей.
- Строгий bounded parser с консервативной политикой: сохраняет оригинал, но ограничивает совместимость и требует контролируемого runtime.

## Decision

Добавить `pypdf==6.20.1`, разбирать strict PDF в отдельном Linux subprocess. Ограничить время, address space, CPU, число страниц/объектов, глубину/узлы и конкурентность. Запретить активные элементы и внешние файловые ссылки. После успешной проверки хранить неизменённый PDF обычным `DOCUMENT`; отдавать только через авторизованное скачивание attachment.

## Reasoning

Это минимальное расширение существующих upload/evidence/review/snapshot без новой очереди, endpoint или миграции. Изоляция parser не блокирует event loop и ограничивает типовые отказы. Отдельное решение человека сохраняет предметные инварианты: принятие формата не доказывает содержание и не добавляет баллы.

## Consequences

Linux Docker становится обязательным runtime проверки PDF. Host Windows получает явный 503 для PDF; старые форматы работают. Строгая политика отклоняет часть легитимных документов, включая формы и действия навигации. Оригиналы не очищаются и не переписываются.

## Risks

Parser и его зависимости могут иметь уязвимости; лимиты не заменяют антивирус и эксплуатационную приёмку. Содержимое потоков страниц не рендерится и не считается полностью проверенным. Два слота ограничивают один процесс API, а не суммарную нагрузку нескольких инстансов. Поэтому текущий сценарий остаётся локальным DEMO/MVP.

## Future Work

Обновления parser с регрессионным набором, независимый hostile PDF corpus, нагрузочные лимиты/quotas и отдельная политика для подписанных или интерактивных документов. Распознавание страниц PDF и автоматическая юридическая проверка в этот блок не входят.
