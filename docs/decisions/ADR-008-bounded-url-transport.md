# ADR-008: Ограниченный HTTPS-транспорт до выбора источника

Status: Accepted for transport only; source integration pending. Date: 2026-10-16.

Дополнение19.10.2026: транспорт подключён к прежнему Primeminister и точной
открытой странице AN GROUPS/payment по явному поручению пользователя. Добавлены
доверенные настройки `allow_subpaths`/`allow_query`: исходное поведение по умолчанию
сохранено, AN разрешает только точный путь без query, включая redirect до
соединения. Это расширение существующей границы, без нового транспорта/сервиса.
Текущая реализация/ограничения — [FEATURE_URL_IMPORT](../FEATURE_URL_IMPORT.md).

## Context

Пользователь задал приоритет C-01 и поручил исследовать рекламные источники. Разрешённый сайт ещё не установлен. Защиту от SSRF/rebinding и ограничение времени можно реализовать и проверить независимо от парсера сайта. Обычный timeout сокета не ограничивает весь DNS/header/slow-body цикл.

## Options Considered

1. Обычный HTTP client с preflight DNS: проще, но повторный DNS при соединении оставляет rebinding, а per-read timeout не является общей границей.
2. stdlib HTTPSConnection с числовым socket, TLS hostname и отдельным процессом под общим timeout.
3. Новый HTTP/proxy/egress service: потребует зависимости и эксплуатации до первого источника.

## Decision

Вариант 2, отдельный модуль без подключения к публичному API. По умолчанию нет разрешённого источника. Один точный DNS-домен и поддеревья путей задаются только доверенной серверной политикой. Только HTTPS/443, без downgrade и сжатых ответов. Проверяются все DNS-адреса и каждый redirect; подключение к проверенному IP с обычной CA/hostname проверкой TLS. Один subprocess на одну попытку, без автоматического retry. HTTP metadata и оригинальные байты возвращаются вызывающему worker после будущей интеграции.

## Reasoning

Нет новых зависимостей и инфраструктуры. Subprocess timeout завершает зависшие DNS/headers/body независимо от socket timeout; проверенный IP исключает повторное разрешение hostname. Транспорт не требует преждевременно выбирать HTML-селекторы или предполагать права на материалы.

## Consequences

Стоимость запуска процесса на один импорт, строго ограниченные формат и схема. HTTP-only, сайты с обязательным JS или gzip пока не поддерживаются. Временная ошибка требует отдельного явного действия. Существующие API/jobs/БД/UI и документы остаются неизменны по поведению; C-01 не считается выполненным.

## Risks

Модуль не является OS network sandbox. Публичный адрес может вести к неподходящему содержимому; доменные условия и парсер проверяются отдельно. Списки специальных адресов Python и правила источника могут меняться. IPv6 сознательно ограничен global unicast без переходных диапазонов. Robots/доступность не являются согласием на копирование. Разрешённый источник и live TLS/fetch ещё не проверены.

## Future Work

Получить разрешение/образец, добавить source-specific extraction, storage/SHA, существующие durable jobs/idempotency/audit, bounded concurrency и UI recovery. Затем проверить реальную интеграцию и ошибки. Расширять HTTPS/encoding/path policy только под конкретный необходимый сценарий и соответствующие тесты. Перед пилотом оценить egress firewall, quotas и мониторинг.
