# ADR-020: Выбираемый отчёт текущего досье

Status: Accepted locally · Date: 2026-10-19

## Context

Пользователь запросил Kompra-подобный отчёт с выбором разделов. Существующий
generic export отдельной записи не охватывает историю/публикации/наблюдения;
PDF сигнала обязан оставаться историческим снимком.

## Options / Decision

Выбран дополнительный authenticated GET properties/{id}/report.pdf с whitelist
разделов и ru/kk. Сводка с неизвестностью/серверным риском/ограничениями обязательна.
Перезапись signal PDF и новая очередь jobs отвергнуты: отчёт не является решением
или сохранённым историческим сигналом.

## Reasoning / Consequences

Отдельная read-only repeatable-read транзакция фиксирует согласованное состояние,
закрывается до существующего ограниченного offline PDF subprocess. Новый trusted
шаблон выводит только whitelist данных; generic renderer и сохранённые signal PDF
сохраняют прежний путь. Нет новой зависимости, миграции или бизнес-команды.

Разделы ограничены100 строками с total/явной неполнотой, пакет1MiB. В источник
включается исходная непроверенная строка импортного наблюдения; она не превращается
в подтверждённую публикацию или Evidence. SHA берётся из сохранённой метаинформации,
оригинал доступен отдельно. Все authored captions RU/KK, свободные исходные тексты
и причины не переводятся. Нативная общая dialog-панель управляет ожиданием/отменой.

## Risks / Future Work

Повтор GET читает новое текущее состояние. Для воспроизводимого решения служит
существующий сигнал. Браузерная отмена не гарантирует остановку уже запущенного
рендера, но серверный timeout/capacity ограничивают его, записи не создаются.
Большое досье может потребовать нескольких отчётов с меньшим числом разделов.
Внешняя языковая/предметная приёмка и физическая печать отдельны от автоматических
тестов извлечения текста и визуального просмотра PNG страниц.
