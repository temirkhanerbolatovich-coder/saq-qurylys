## Поисковые фразы RU/KZ ·19.10.2026

В «Сверке» → «Источники» → дополнительный поиск Threads появился native details
«Подготовить фразы RU/KZ». Версия1.0:9вариантов города/региона и4темы оплаты;
каждая фраза содержит ЖК/тұрғын үй кешені, в т.ч. короткие УКА/ВКО/ШҚО.
Можно выбрать язык фразы независимо от языка интерфейса и добавить название ЖК.
Кнопка фразы меняет только текущий черновик Threads и переводит туда фокус.
Enter в параметрах конструктора не отправляет поиск; сам поиск — отдельная
прежняя команда с действующей проверкой доступа. Браузерный поиск других сайтов
и расписание этим блоком не реализованы.

Это редакторские подсказки, не извлечение платёжных фактов и не оценка риска.
Никаких новых API/DB/jobs/решений/запросов к внешним площадкам. Параметры helper
живут в mounted UI: вкладки их сохраняют, reload сбрасывает. Справочник пока
не редактируется и не сохраняется на сервере. До scheduler понадобится хранить
версию/параметры каждого задания и выполнять независимые серверные проверки.

Изменения: frontend/lib/monitoring-queries.ts, components/monitoring-query-builder.tsx,
threads-search.tsx, monitoring.css, tests/monitoring-queries.spec.ts.
