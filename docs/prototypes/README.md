# Локальные макеты SAQ QURYLYS

[analyst-workspace.html](analyst-workspace.html) — самостоятельный HTML для
согласования обзора, реестра и досье. Открывается обычным браузером без установки
зависимостей и без API. Цвета/типографика следуют проектному master1.4;
это отдельный артефакт предложения, а не новая тема приложения.

Кликабельны переходы между тремя экранами, поиск по восьми синтетическим строкам,
фильтр/сброс реестра, переход в досье, шесть локальных вкладок и стрелки/Home/End.
Кнопка решения выводит пояснение и ничего не отправляет. Другие рабочие зоны
показаны для структуры и отмечены «вне макета».

Все объекты, цифры, документы и решения вымышлены и отмечены DEMO. Это проверка
композиции и переходов, не функционирующий новый backend, не измерение качества
анализа и не уже установленный редизайн. Формулы/интеграции не меняются.

19.10.2026 пользователь «окок» согласовал направление. Композиция перенесена
в приложение локально (master1.5), с сохранением действующих функций и без
выдуманных команд макета. HTML остаётся исходным предложением и не подключается
к API. Контекст
и критерии — [референсы](../audits/SAQ_QURYLYS_PRODUCT_REFERENCES_2026-10-19.md)
и [аудит функционала](../audits/SAQ_QURYLYS_FUNCTIONAL_AUDIT_2026-10-19.md).
