## Найденный дефект: статистика дважды учитывает PENDING

**P2, воспроизведён, не исправлен.** При5CONFIRMED и1PENDING интерфейс показывает
«Подтверждены5 / Ожидают решения1 / Отклонены0 / Не установлены1»:
семь элементов при шести кодах. Балл95остаётся корректным.

Причина: `frontend/components/dossier-overview.tsx`, `DossierRiskStatistics`,
берёт последний счётчик из backend `risk.unknown_codes`, где PENDING также
является неподтверждённым. Соседний счётчик уже учитывает PENDING отдельно.
Это расхождение семантики представления, не ошибка формулы.
Следующий связный фикс: считать отдельные UNKNOWN/отсутствующие факторы
либо явно обозначить пересечение групп; добавить regression-проверку
смешанных статусов и проверить установленный UI. Backend unknown_codes
не менять ради исправления счётчика. Рекомендации ui-ux-pro-max использованы
для оценки контекстного feedback; проектный master сохранён.
