## Решения классификации

KEEP — код, миграции, fixtures, API, ADR, данные синтетических оценок и лицензированный Skill сохраняются. MOVE — первичные DOCX/PDF переходят в docs/reference с обновлением ссылок. MERGE — актуальные входные документы сокращаются, полные прежние версии остаются в docs/archive. REVIEW — только неоднозначные дубли evidence; автоматическое удаление запрещено. REMOVE — доказанных кандидатов среди исходных файлов нет; кэши исключаются из build context, пользовательские файлы не удаляются.

Архитектурные entry points: frontend/app/layout.tsx и frontend/app/**/page.tsx; backend/app/main.py:create_app; backend/app/worker.py; backend/alembic/env.py; contracts/openapi.yaml; scripts/configure_local.py. Backend image собирается из корня и читает versioned seed, frontend dictionary и docs JSON. Frontend image собирается из frontend/. CI использует те же пути. Перенос runtime-кода не нужен.
