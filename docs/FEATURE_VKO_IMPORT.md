## Операторский сценарий

`scripts/replace_demo_data.py --source <directory> --backup <verified-backup> --verification <restore-result.json> --container <database-container> --output <project/.local/directory>` выполняет ROLLBACK по умолчанию. `--apply` явно применяет транзакцию. Инструмент предназначен только для этого фиксированного пакета и primary `saq-qurylys-db-1` или offline `saq-vko-rehearsal-*`. Требует совпадения fingerprints с backup, остановленных API/worker, успешного restore check и `DEMO_SEED_ENABLED=false` для primary. Повторное применение к уже изменённой базе отклоняется. База блокируется на время транзакции; REAL-зависимости от удаляемых DEMO приводят к отказу. Сырые CSV/XLSX не публикуются через API, сохраняются побайтно в приватном архиве. Не запускает внешние загрузки, анализ, risk confirmation или уведомления.

Старт Compose проверяет `DEMO_SEED_ENABLED`: default true для учебной установки, false пропускает seed, прочие значения останавливают startup. Не включайте true для рабочей базы ВКО. Прямой ручной `python -m app.seed` остаётся явной командой загрузки DEMO.
